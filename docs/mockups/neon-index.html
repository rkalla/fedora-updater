BONUS · Verified Fedora 44 Native Platform Upgrades (Tier 2)

1. DNF5 via System D-Bus (org.rpm.dnf.v0) Verified active: dnf5daemon-server 5.4.8.0. Unlocks zero-password Update Checks, eliminates GNOME Software lock stalls, exposes real old → new versions, CVE advisories, download MB/s, History.list(), and Offline reboot updates.
2. Flatpak via libflatpak.so.0 Transaction API Extends the existing FFI in src/backend/flatpak.rs to run FlatpakTransaction directly with FlatpakTransactionProgress, GCancellable, AppStream icons/changelogs, and zero-prompt allow_active = yes polkit rules.
3. Firmware via org.freedesktop.fwupd D-Bus Verified active: fwupd 2.1.9. Reads live PercentageFull, device history, release notes, and BatteryLevel vs BatteryThreshold to warn before flashing BIOS on low battery.
4. System Reboot & Background Notifications Queries org.freedesktop.login1.Manager (CanReboot, ListInhibitors, Reboot(true)) and sends native gio::Notification alerts when updates finish while unfocused.
