Phase 1 principles

  • Host changes only via CLI (dnf, systemctl)
  • Elevation via polkit / pkexec (no password capture)
  • Parse stdout/stderr → GUI rows
  • Console collapsed to 1 live line
  • Completed items burn down into a collapsed top section
  • gtk4-rs + libadwaita · GNOME system styling
